Beta 1.1 is the enchantment content wave — 26 new enchantments across every combat and tool slot — plus a new unbreakable-item system, Everfeast rations, and a redesigned recipe-viewer experience.

## Added

- **26 new enchantments** spanning melee, ranged, armor, shields, mining, and traversal: Ambush, Pinpoint, Sunder, Trophy, Fortuity, Crescendo, Riposte, Joust, Longshot, Seeker, Harpoon, Blink, Inexorable, Emberward, Reprieve, Loft, Hush, Decoy, Bastion, Everbloom, Grind, Adamant, Reclaim, Timberfell, Grapnel, and Thermal.
- **Everfull Flask** and **Tempered Core** — a new unbreakable-item system. The Dormant Core drops from the Ender Dragon and is upgraded at the anvil.
- **Everfeast rations** — a new infusion for food items.
- **Tether** — a shared keep-on-death enchantment that integrates with the `#c:soulbound` tag, converging with other mods that use the same system.
- Enchantment descriptions now appear when hovering over books in EMI, REI, or JEI.
- The Infusions browser in EMI/REI/JEI has been redesigned with colored stat bars.
- Tooltip teaching text added to enchanting stats, shelves, and the library — hover anything to learn what it does.
- Anvil pages in EMI/REI/JEI now explain how tomes work with the anvil.
- XP tomes can now pay enchanting table costs directly without separate XP.
- The craft slot highlights visually when a recipe match is found.
- The advancement tree has been reworked with usage-triggered advancements and new anvil and stat branches.

## Changed

- Server config values now sync to connected clients automatically.
- Duplication recipes and Everfeast recipes can each be toggled off in the config.
- The Tempered Core system can be disabled in the config.

## Fixed

- The enchantment library and filtering shelf now show clear success and deny feedback when inserting or rejecting books.
- An error thrown by one enchantment's effect handler no longer interrupts other enchantments ticking on the same entity.
- The projectile bounce tracker no longer carries stale state across server restarts.
